# Code of Conduct

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, and keep discussions about the work.
Harassment or abusive behavior is not tolerated.

Report concerns privately to the maintainer through a GitHub Security Advisory
(**Security -> Report a vulnerability**) or by email listed on the maintainer's
GitHub profile.
